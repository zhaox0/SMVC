Abstract

Expressive voice conversion (VC) aims to transfer speaker and emotional characteristics while preserving linguistic content. However, existing methods often rely on global style embeddings and a single reference modality, limiting fine-grained style modeling and adaptability to diverse scenarios. To address these issues, we propose Switchable-Modality Voice Conversion (SMVC), a unified expressive voice conversion framework that supports either facial cues or speech as the target reference. SMVC comprises three key modules. The Content-Synchronous Time-Varying Style (CSTS) module for content-synchronous dynamic style modeling, a multimodal style encoder that uses a normalizing flow to map facial embeddings into the speech style space for flexible modality switching, and a content processing block incorporating a style-dependent duration predictor and PMix for target style adaptation and source speaker disentanglement. Experiments show that SMVC consistently outperforms compared face-based VC methods and remains competitive with speech-based methods under both Seen-to-Seen and Unseen-to-Unseen scenarios. Modality-switching experiments confirm that a single jointly trained model effectively supports both reference modalities, and ablation studies verify the contributions of each key component.
